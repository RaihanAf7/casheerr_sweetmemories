# 🍩 Sweet Memories — Web Point of Sale (POS)

> *"Dibuat dengan rasa, dikenang selamanya.."*

Aplikasi kasir (*Point of Sale*) berbasis web yang dirancang ringan dan responsif untuk mendukung operasional penjualan **Sweet Memories**. Sistem ini dilengkapi sinkronisasi data *real-time* serta pembatasan hak akses antara pengunjung dan kasir.

---

## ✨ Fitur Utama

- **Katalog Menu & Pencarian Cepat:** Filter kategori (*Semua, Makanan, Minuman, Aksesoris*) serta pencarian menu secara instan.
- **Kustomisasi Varian Produk:** Pemilihan tipe dan varian harga khusus untuk produk aksesoris (*Gelang, Kalung, Cincin Manik-Manik Custom*).
- **Manajemen Keranjang & Antrean (Hold Order):** Menyimpan pesanan sementara ke daftar **Pesanan Pending** sebelum transaksi diselesaikan.
- **Metode Pembayaran Tunai & QRIS:** Perhitungan kembalian otomatis dengan pilihan nominal cepat serta tampilan kode QRIS.
- **Cetak Struk Thermal:** Pratinjau struk kasir siap cetak (*auto-print* maupun cetak ulang dari riwayat transaksi).
- **Laporan Penjualan & Export Excel:** Ringkasan omset, jumlah transaksi, menu terlaris, dan ekspor laporan ke format `.xls`.
- **Mode Akses Publik & Kasir:** Pengunjung dapat melihat katalog dan ringkasan data secara *read-only*, sementara pengelolaan transaksi hanya dapat dilakukan oleh admin terotorisasi.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend & Cloud Sync:** Firebase Realtime Database & Firebase Authentication
- **Ikon & Tipografi:** Font Awesome 6, Google Fonts (*Plus Jakarta Sans*)
